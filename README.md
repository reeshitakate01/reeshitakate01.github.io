# reeshitakate01.github.io

Personal portfolio of **Reeshita Kate**, cybersecurity student focused on application security and security engineering (Pune, India).

Live at **https://reeshitakate01.github.io**

Plain HTML, CSS and JavaScript with no build step and no frameworks.

- **Privacy:** no analytics, trackers, cookies or forms. The front-page "what your browser told me" card is computed entirely in the visitor's browser and never sent anywhere.
- **Security:** a strict Content Security Policy (`script-src 'self'`) and no third-party scripts. Fonts come from Google Fonts.
- **Credits:** the animated gradient and logo use [Paper Shaders](https://github.com/paper-design/shaders) (Apache-2.0), served from `vendor/` with its license.
