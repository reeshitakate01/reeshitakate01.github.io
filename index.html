story time

How did I find one bug in almost every endpoint?

the answer

I threat-modelled the API before poking at it. Once I saw how tenants and IDs were handled, I swapped one user's IDs into another's requests. It worked nearly everywhere, which meant account takeover, privilege escalation and session hijacking. I wrote it up, they patched it, and I re-tested every fix.

  1. 🔍🧭🗺️🔦

  2. 🧪📸📏🧾

    Prove

  3. 🛠️📝🔁✅

  4. 🤖⚙️📦🧠

chapter 02 · the story so far

How I got here

I got into security after seeing how easy an attack can be. Now I look for those weak spots before attackers do, and help teams fix them.

  1. 01

    where it started

    It started close to home.

    Someone in my family got scammed over a phone call. The attacker barely had to try, and I couldn't stop thinking about it. How did it work, and how could it be made harder?

  2. 02

    learning the craft

    So I learned it properly.

    I chose a B.Tech in cybersecurity, picked up certifications from ISC2, AWS, IBM and Cisco, and did internships in ML, web and security. The trickiest part was learning to think like an attacker, then explaining it in a way engineers would act on.

  3. 03

    the moment it clicked

    One number changed everything.

    During my internship at Sciqus, I changed a single ID in an API request and saw another user's data. The same flaw showed up almost everywhere. I proved it, reported it and checked every fix myself, and it was closed before anyone could misuse it.

I watched how easy it was for an attacker. Now I make it hard.

Federated learning IDS for IoT

Problem
Centralised intrusion detection needs everyone's raw traffic, and it breaks down on networks it hasn't seen.
What I did
Trained a multi-encoder DNN plus AutoEncoder with federated learning across three public IoT datasets (11M+ samples). Devices share model updates, never raw traffic.
Result
90%+ accuracy on unseen environments against 25 to 40% for centralised models, with under 1% false positives.
  • TensorFlow
  • Federated learning
  • IoT
